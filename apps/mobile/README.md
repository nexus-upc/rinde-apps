# RINDE Mobile

Carpeta de la aplicación Android para el conductor, prevista en Kotlin para el Sprint 3. El repositorio anterior estaba vacío y no tenía commits, fuentes ni configuración Gradle que migrar.

Al iniciar la implementación, crear aquí el proyecto Android con su wrapper, build y configuración propios. La aplicación usará el gateway y conservará el alcance de registro offline. No hay todavía una aplicación móvil que compilar.
